💀 Ahorcado

El clásico de siempre. Elegís letras del teclado en pantalla, una por una: si la letra está en la palabra oculta, se revela en su lugar; si no está, se dibuja una parte del cuerpo del ahorcado. Si el dibujo se completa (6 errores) antes de que adivines la palabra entera, perdés la partida.

🟩 Adivina la Palabra

Estilo Wordle en modo difícil. Te decimos cuántas letras tiene la palabra oculta y escribís tu intento completo. El color de cada letra te da la pista: verde = letra correcta en ese lugar, amarillo = la letra está en la palabra pero en otro lugar, gris = la letra no está. Tenés 5 intentos para adivinarla.

🎓 Acerca del Proyecto

Proyecto Integrador Final - UniGames

Universidad Tecnológica Nacional (UTN) - Facultad Regional Tucumán

Carrera: Tecnicatura Universitaria en Programación

Materia: Desarrollo Web Full Stack & Base de Datos II

Resumen: UniGames es una Plataforma Web de Minijuegos Didácticos implementada como una Single Page Application (SPA). Diseñada con arquitectura Full-Stack cliente-servidor para fomentar la agilidad mental y mejorar el vocabulario.

💻 Tecnologías Clave

Arquitectura y Herramientas

🎨 Frontend: SPA construida con HTML5, CSS3, JavaScript ES6+ e interfaz Glassmorphism.
⚙️ Backend: API REST robusta en Node.js con Express.
🔒 Seguridad: Autenticación JWT y encriptación Bcrypt.
🗄️ Base de Datos: SQLite (Modelo normalizado 3FN) con integridad referencial.
🏗️ Patrones: Arquitectura POO (herencia/polimorfismo) y metodología ágil Scrum.

🎮 Tutorial Rápido

¿Cómo usar UniGames?

  • 1. Elegí un juego: Navegá por el catálogo en la pantalla principal.
  • 2. Seleccioná temática: Antes de jugar (ej. Preguntados, Ahorcado), podés filtrar por Videojuegos, Películas, Anime o Programación.
  • 3. Compite: Registrate e iniciá sesión para guardar tus récords. Los mejores puntajes aparecen en la Leaderboard Global.
  • 4. Tip Pro: Cuanto más rápido respondas y menos vidas o pistas uses, ¡más puntos sumarás!
